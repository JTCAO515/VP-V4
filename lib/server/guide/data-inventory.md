# Guide selection data inventory

Scope: `guide_selection_metadata`, version1. This is the Guide module's selection export/delete consumer. It is **not enrolled** in the existing all-account `core-export-d2/1` worker; original grounded history/results and Ops use-review audit belong to their existing separate modules. No complete-all-account claim follows from this inventory or the scoped export.

| Retained data | Authority and lifetime | Actual export consumer | Actual deletion/invalidation consumer |
| --- | --- | --- | --- |
| `guide_private.progress_v1`: canonical/ref/locale/explicit interest, digest/rights revision, completed segment IDs, absolute expiry | Ordinary owner/session + current Trip/reference + current independent source/use qualification; only cache=true permits storing progress | `guide_place_v1(action=export)` → owner HTTP → Native Guide scoped ShareLink; metadata `records` only | `guide_place_v1(action=forget)` clears selected progress regardless of stale head/source; source/use/canonical/member/session/Trip triggers remove stale rows; owner/Trip/reference/session FK cascades |
| `guide_private.bindings_v1`: exact original grounded turn/task/op, owner/session/Trip/reference, source-use digest and safe proof metadata | Original standalone grounded admission unchanged; immutable Guide proof binds the selection. No source body or question copy. Old proof/op never transfers to a new Trip or actor | Same actual scoped route/caller exports safe `bindings` fields; no raw source/question, credentials or temporary played positions | Forget/source/use/identity/Trip deletion invalidates proof and clears temporary positions; original turn/owner deletion cascades. Nonreplayable markers can remain to prevent an old guided turn entering ordinary unmarked execution |
| Explicit `follow_up.completedSegmentIds` transient prompt input | User submits conservative system speech played-segment position, max4 unique current segment IDs. Cache permission independent. For cache=false, retain only for this pending original turn/session/source TTL; not readable as replay progress | Excluded from permanent binding metadata export; no perpetual progress export without cache permission | SQL terminal/expiry/source/session/forget/delete cleanup clears positions, preserving the deny marker. This cleanup is required for final package completion |
| Native Guide ready receipt and local played position | In memory; endpoint/owner/mobile epoch/Trip/ref/canonical/locale/interest/source digest/rights/expiry fenced. Playback/resume requires new matching current receipt | Source text is shown only while current display use is allowed; scoped metadata ShareLink deliberately contains no source text | `NativePlaceGuideStore.suspend/clear`, view disappearance/background/session change and Session cleanup stop playback, clear display/progress; no automatic playback on restore |
| Native pending follow-up operation | Protected original-account journal for exact request bytes and same-op retry; original question/explicit position only, bounded absolute source expiry; fresh actor/source/use check before retry | Separate original question/history module. The Guide selection metadata export does not represent this as stored progress or all-account content | Native Session Guide journal cleanup on signout/account/epoch/endpoint change; terminal/expiry/source denial removes pending bytes; uncertain acknowledgement retries exact bytes only |

Actual public entrypoints: `app/api/guide/native/v1/trips/[tripId]/route.ts` and `app/api/guide/trips/[tripId]/route.ts` → `lib/server/guide/http.ts` → `runGuide` → `public.guide_place_v1(uuid,jsonb)` in `20261005080000_place_guide.sql`. Export/forget use ordinary owner identity; no service credential, new provider dispatch or Trip writer.

Actual Native consumer: `Features/PlaceGuide/NativePlaceGuideView.swift` export/forget actions and `NativePlaceGuideFollowUpStore.swift`; protected journal lifecycle in `App/NativeSession.swift`. SQL use-review capability defaults deny and requires independent existing Ops membership; this code does not enroll a real publisher, licence or target RPC ACL.

`scope=guide_selection_metadata,coverage=complete_for_selection` refers only to this safe selection metadata projection. Both arrays have a100+sentinel bound; capacity is returned instead of silently truncating. Lost/expired source rights permit safe owner metadata export/forget, never restore source values. Unrun target coverage/voice/provider/human quality stays separate from source and owned fixture evidence.
