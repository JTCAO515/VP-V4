# VisePanda Brand Delivery

This directory is the digital-first VisePanda visual-identity delivery for international visitors travelling in China. It is English-first and implements the approved direction: **Your warm local friend in China.**

## Source and provenance

The owner-supplied source assets remain immutable at:

- `assets/brand/vise-panda/VP-Logo.svg`
- `assets/brand/vise-panda/VP-Logo.png`
- `assets/brand/vise-panda/VP-正面全身.png`
- `assets/brand/vise-panda/VP-三视图.png`

No file in that source directory is modified by this delivery. New, derived work is contained in this `brand/` directory and can be removed as one rollback unit.

## Contents

| Folder | Purpose |
| --- | --- |
| `tokens/` | Canonical colour, type, layout and material tokens. |
| `guidelines/` | English visual-identity handbook, including brand foundation, fixed-logo application concepts, voice, type and social rules. |
| `ip/` | Transparent VisePanda Guide pose library. |
| `icons/` | Utility, map-pin and pattern SVG assets. |
| `social/` | Ready-to-post avatar, feed, Story/reel and end-card exports. |
| `ui/` | Web and mobile component reference sheet. |
| `qa/` | Asset manifest and final verification record. |

Open `guidelines/visepanda-vi-guide.html` in a modern browser for the handbook. Read `tokens/visepanda.tokens.json` before implementing the system in a product.

For final inventory, validation evidence and rollout considerations, read `qa/asset-manifest.json` and `qa/verification.md`.

## Usage guardrails

- Keep the supplied logo and panda character intact; do not redraw, stretch, crop destructively or recolour source artwork.
- Use gold as an accent, never the only signal for critical information.
- Keep body copy high contrast and controls at least 44 × 44 px.
- Do not present VisePanda as an official government, transport, visa, emergency or booking authority.
