# VisePanda IP Original v1.1

这是 VP IP 的原版角色参考包，包含正面、背面、左侧和右侧四张转面图，以及对应的设计和生成提示词。

## 固定元素

- 无衣服的 3D 熊猫原型：圆头、圆肚、短四肢。
- 手掌、脚掌及指肚为浅蜜桃白色肉垫。
- 单边智能耳麦固定佩戴在角色解剖学右耳；耳罩与脸部保持可见间距，蓝色灯带和延伸至嘴旁的麦克风为固定识别元素。

服装、手持物和场景不属于固定元素，可按具体传播需求更换。

## 使用范围

本包仅用作 `brand-reference` 与 `design-review`：为后续服装、姿态、动效和传播物料保持角色一致性提供参考。它不构成运行时页面资源或已发布素材。

`generation-prompts.json` 与 `revision-prompts.json` 保留生成过程中的提示词和本地来源路径，供内部追溯使用；文件中的来源记录本身不构成对外发布或授权证明。
