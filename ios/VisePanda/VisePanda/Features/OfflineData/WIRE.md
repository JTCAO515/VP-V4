## Writers and deletion isolation

All actual writers are covered: Today.saveLocal synchronous explicit new edit captures a namespace write ticket; Today.saveSnapshot captures nonce/generation/request start before network await and the original verifier validates the matching signed response; Hotels.saveLocal captures generation before refreshForSharing await and keeps existing revision CAS. Store save methods require exact tickets. No old async response may obtain a new generation or reuse an old permit with a new nonce. NativeTripStore.restoreOfflineUserDraft rereads exact original draft/generation before and after await, preserving original visible Proposal/explicit confirmation.

Every original removeTrip route uses the same original three-file cleaner inside the generation fence: Today explicit remove, Trip archive/deletion/revocation paths and selected DataCoverage cleanup. Namespace generation is persisted before deleting any sources. During incomplete cleanup all source read/write tickets fail closed. A retained exact operation can be explicitly resumed; new operation IDs cannot replace an unfinished admission. After all three files and index are independently verified absent, a minimal immutable result for that operation is encrypted/read-verified. A later explicit save captures the current generation and remains legal; an old ticket fails across Store instances/restart. The latest generation/admission and receipt retain only namespace, generation, UUID and verification time, no erased content or pending command bytes. Later explicit cleanup supersedes the latest receipt with a new operation; an existing same-operation receipt is never edited or regenerated. Historical receipt describes verification time, not absence after new explicit saves.

Selection recovery merges the original index with bounded exact encrypted cleanup admissions in the current account folder, so an interrupted cleanup remains selectable after its index entry disappears. No guessed identifiers or server lookups. Partial deletion/error is unknown until the same original admission completes; it never reports empty/success.
