# VPJ-27 — on-demand native voice translation

The Translation screen links to a dedicated native voice screen. The concrete session-owned `NativeVoiceAudioController` is the only microphone, local recognition and speech producer. This implementation reuses the existing text translation API, current-input consent, budget and original request recovery; it introduces no audio server endpoint or provider.

Press begins at most30 seconds of mono16kHz int16 PCM. Core synchronously returns the sole recording UUID before any asynchronous permission request. Release during permission waiting cancels that identity and generation; late permission cannot start recording. Release during capture stops the recorder and requests only final on-device recognition of that one protected temporary file. Device/locale unsupported, permission denied, unavailable language resources or recognition failure leave typing available. There is no continuous listener, contextual history, network ASR fallback or model/resource download request.

The final callback carries the exact original final text, recording UUID, actor scope, measured PCM seconds and UTF16 character count. Original ASR text is bounded to600 UTF16 units. A stale identity/scope, duplicate final, oversized original, invalid format or unsuccessful deletion cannot publish downstream text. UI exposes the final subtitle and editable review; only explicit confirmation sends reviewed text via `NativeTranslationStore`. The original final subtitle remains distinct from a user-corrected submitted original.

Unknown acknowledgement first refreshes the saved result for the original pending turn and consent notice. A retry keeps the original turn/idempotency key/policy/text. Recent unrelated history is never selected as this recording's result or sent as context. Only the exact saved translated turn with matching submitted original, source language, actor and governing policy becomes the final translation. Withdrawal, denial and account change hide unauthorized results and cancel audio; a network failure leaves authorized loaded text readable. Translation fees remain unknown until the original service measures them.

Speech requires an explicit button. It selects the exact final translated text (up to2400 UTF16 units), never back-translation or partial text, using an enumerated installed Apple system voice for the target language. No implicit default, personal/third-party voice or download path is selected. The same final text ID cannot start again in the same actor scope, including after stop or interruption. There is no autoplay or automatic resume. System callbacks expose conservative progress; they do not assert acoustic measurement or a price.

Call/route/background/protected-data/media-reset interruptions cancel active capture/recognition/playback and invalidate callbacks. Scope binding, explicit cancellation and session logout/clear erase temporary audio; failure preserves a storage fence before new audio or account activation. Only one protected, backup-excluded local temporary copy exists, bounded by120-second TTL and startup purge. Anonymous EntryResume preservation and original journals are unchanged.

Microphone and speech usage-description source strings are declared; only a user press reaches permission request code. No real permission popup or human recording was exercised by this delivery. `artifacts/VPJ-27/verification.md`, `unrun.md` and `commands.jsonl` distinguish actual fixture results, compilation failures, full-app build and unrun system/device/provider/human checks. Rollback removes the voice entry and its newly registered sources, leaving the text translation lane intact.
