## VPJ-72 的最小范围

复用 `evals/harness/pairing` 的输入、版本及报告，不另写模型 router 或第二评分平台。新增测试和结果投影集中在 response-quality/盲评范围；主配对入口的必要相邻改动须明确由一位实现者负责。优先 JSON/Markdown；只有交互确实不足才选本机 Gradio，不默认 Argilla/Distilabel 或公网分享。

内容和语气分维度：回应目标、事实与限定、下一步、偏好适用、信息密度、英文自然度、情境语气。硬失败独立否决，不与软分平均：虚构行动成功、未确认修改、错误证据、泄露、撤回后使用、无接单回执却声称真人已接手。正常可答场景的过度拒绝也要检出。

输出包沿用同一版本化报告，包含 A/B 隐名和顺序交换、平局/都失败、明确评分来源以及反馈导入校验。自有合成标注只验证工具，不写成人工评价。原有8开发/4holdout分组保留；暴露或用于调优的样本登记为开发数据，不冒充新盲测，不为凑数量扩大12场景主验收集。

HF Judge/Guidebook借方法，LongMemEval借更新与跨会话分类，TravelPlanner借行程约束测试结构，BIPIA借攻击分类。先使用自有合成例；导入外部数据时，记录准确资源ID/revision/原行ID/许可和转换方式。JSON标准库足够时不加Datasets；必要的数据转换在离线环境完成。

## VPJ-73 的最小范围

只评估 Docling 是否能减少当前材料输入的重复工作。优先合成中英旅行截图；允许一个可搜索PDF作为解析对照，测试对照不扩张 #201 的单张截图合同，多页与分享仍归 #236。只输出有原材料ID、位置、字段和不完整标记的校正候选，不接真实用户、知识发布或 Trip writer。

在运行前固定框架版本与所用模型/解析器及其各自许可。SmolDocling 当前模型卡许可冲突未解决，不作为默认权重；不得为了跑通而启用未审远程代码。保留远程服务、外部插件及公网分享关闭；首次权重下载与真正离线运行分开记录。可运行分支测试实际取消/超时、输入限额、OCR错误和材料内恶意指令。运行前固定小型中英样本、关键字段及原位置真值、采用/否决判据和输入/时长/内存的有限上限，不在结果出现后挑样或改标准。

试验结论为 ADOPT 或 REJECT，并附关键字段、来源位置、失败与实际资源证据。遇到无法运行的许可/兼容性问题，只有固定组件/版本、具体阻断证据及替代路线评估齐全时才作有据的 REJECT，并明确转换和性能UNRUN；仅未安装、未运行、缺环境不得伪造采用结论或完成。若研究被外部条件卡住且尚不能形成可复现的否决依据，保留 UNRUN 和开放状态。

## 调度与文档责任

本规划合并后重新核就绪：72和73在范围、契约与本地条件确认后可并行；已有原生、provider/预算工作继续。72主要写response-quality测试/报告，73主要写材料转换试验及本票证据；共享pairing入口、锁文件、根handoff和manifest由主agent协调，避免重复改动。

每项PR完成其有界结果，独立审阅和必需CI保留；准备完成只关闭准备票。真实父票的状态、历史评论和完成勾选保留；不因本次加验收就自动改为ready。每次合并依实时依赖重算可推进项。

回滚本规划可撤销本批文档和新增验收；新增票按未计划/被替代保留历史，仅移除本批新增依赖，不改既有依赖和数据。已发生的模型消费、用户Trip和已应用迁移不由文档回滚撤销。
