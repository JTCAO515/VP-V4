# Journey Pass 开发态展示规则

读取 `journey-pass-catalog/1` 时，界面只能把 Journey Pass 表达为“开发中，尚不可购买”。不得根据 USD 参考/备选数字展示本地实际价格、付款按钮、自动续费、人工包含或无限服务。

Free 和 Pass 均可说明用户明确保存的基础跨 Trip 偏好以及 Trip/数据控制；这不扩大同意、数据接收方或模型消费范围。服务任务容量在当前版本未决定，界面必须不展示次数、剩余量、刷新时间或“无限”承诺。

实际 StoreKit 产品、地区价格、税费、合同主体、购买/恢复/退款状态仅在 #226 的已验证 Sandbox 或发布环境中读取后才能面向用户展示。
