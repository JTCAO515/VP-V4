**Goal:** Deliver safe, localized city-first Explore routes that truthfully remain unavailable until a single eligible projection exists.

**Architecture:** App Router routes delegate to one locale-aware client component. It has no query, seed, map, data source, write action, or identity parsing; future data must enter through the existing reviewed/current/licence-allowed Fact boundary.

**Tech Stack:** Next.js App Router, React, TypeScript, CSS Modules, Node test runner.
