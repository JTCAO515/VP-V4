## 产品和技术约定

- 高德是首个主候选，腾讯同步接入开发探针；正常请求不默认双调用，主次由实测决定。首期只加载一套主地图展示SDK；统一服务端适配搜索/详情/地址/路线/矩阵/导航出口，高级能力显式声明。
- 内部canonical身份与provider ID分开；地址别名、父子地点、入口和坐标均保留来源。明确经纬顺序与WGS/GCJ转换记录，禁止重复转换、模糊自动合并、建筑中心替代入口。
- 地图供应商观察和已审核旅行Fact分开。中英同事实、中文原名和地址可给司机看；模型可以解释/消歧，不能捏造坐标、ETA、营业、外卡或无障碍能力。
- 步行/公交/驾车方案展示耗时、距离、换乘、费用估算、出发与查询时间、缺失项。规划不等于导航完成、公交实时到站、叫车报价、购票或履约。未来预测不等于当前路况。
- Trip调整仍走精确版本Proposal→diff→用户确认；路线/事实变化不静默改已确认行程。矩阵先筛候选、限制元素/并发、只重算受影响段，按实际计费单位记账。
- 服务端Key与应用/域名受限展示Key分离；固定官方上游、限制请求/响应、超时/重试/每任务预算。日志脱敏，不默认保存精确用户轨迹或完整上游响应。
- 坐标/查询发送给第二供应商前核对用户同意；鉴权/配额错误明确处理，不用无限fallback掩盖。切换重新生成完整路线，保留来源，不拼路线或平均ETA。
- 缓存、展示、传模型等用途逐字段确认可用范围；无依据时收窄使用。账号可用即可开发，未知商业条件记录；不等待供应商书面答复，也不据此假定无限复制/再分发权。高级室内/未来ETA/可达圈按权限、实测收益和预算逐步引入。
