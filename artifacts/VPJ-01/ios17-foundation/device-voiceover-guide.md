## 1. 先让 Mac 能识别手机

1. 用可传输数据的 USB-C 线连接 Mac 和 iPhone，解锁手机并保持屏幕亮着。
2. 若手机出现“信任此电脑”，仅在手机上按提示完成。无需向聊天发送解锁码或账户密码。
3. 在 Mac 的 Finder 侧栏确认能看到这部 iPhone。若没有，先换一个数据接口/数据线，再解锁重连。
4. 告诉 root“已连接并解锁”。root用以下**只读**命令复核；仍为 `unavailable` 时不要开始安装：

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun devicectl list devices
```

不要为这一步删除App、重置手机、清空信任设置、删除证书或修改项目Team。

并确认是否会覆盖手机上的已有App。现有模拟器 `.app` 不能当作真机安装包。

当前设备不可用，尚未核验已安装版本及是否会覆盖数据。先准备具体真机构建和影响，再判断会话现有授权是否覆盖。
只有新增签名/账户配置或可能覆盖未知数据等超范围动作才需确认；不为同范围操作重复申请授权。
未核实版本与覆盖影响前，不直接在Xcode按Run或卸载现有App。不匹配版本的观察可记作参考，不能算当前代码通过。

若核对后采用Xcode本地安装，且需要Developer Mode：

1. root先用现有配置完成设备配对并确认是否需要 Developer Mode，不新建账户/证书来绕过错误。
2. 需要时，用户在手机“设置 → 隐私与安全 → 开发者模式”开启，按提示重启并在手机上确认。
3. 若没有该菜单，先完成 Xcode设备配对；不要自行重置系统或清空信任关系。
4. TestFlight/App Store安装不因这次测试自动需要开启 Developer Mode。

依据：[Apple开发者模式说明](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)。

## 3. 先做普通字号的中文/英文检查

以下均以 root确认过的**原生基础预览版本**为前提，不登录、导入真实材料或创建真实行程。

1. 打开VisePanda，确认默认是“问熊猫 / Ask”，底部五个入口能识别。
2. 在“我的 / Profile → 语言 / Language”选择中文，依次看 Ask、Trip、Tools。
3. 只在输入框输入 `Access test 123`，点“完成 / Done”收起键盘。发送应不可用，不能出现已发送/已保存。
4. 改选 English，返回Ask，确认草稿仍在，导航与说明切换为英文。回中文再核对一次。
5. Trip应该明确是空行程；编号1/2/3和步骤文字应能看清。Tools三个入口能进入预览说明并返回。

遇到截断、遮挡、跳错页面或草稿丢失，记FAIL并附当前App页面截图，不继续把这一项勾成通过。

## 4. 开启旁白，逐项朗读和操作

1. 手机“设置 → 辅助功能 → 旁白（VoiceOver）”开启；不熟悉时先使用该页的“旁白练习”。
2. 基本操作：单指左右轻扫切换焦点，单指双击激活，三指上下滑动滚动页面。
3. 返回VisePanda。中文和英文各走一遍下表，记录实际听到的关键句或异常。

| 页面/动作 | 应观察到的结果 | 当前记录 |
| --- | --- | --- |
| Ask顶部 | 品牌和说明可理解，不朗读图片文件名/本地化key | UNRUN |
| 预览说明 | 完整表达未连接实时数据、账号、AI、预订或支付；不能只读到一半 | UNRUN |
| 输入框与发送 | 输入框可定位/编辑；发送可识别为不可用；没有虚构发送结果 | UNRUN |
| 关闭键盘 | “完成/Done”可找到并激活，键盘退出，草稿保留 | UNRUN |
| 五Tab | 可听出名称与选中状态，能切换且没有焦点陷阱 | UNRUN |
| Trip空状态与三步骤 | 空行程说明、编号和步骤按可理解顺序朗读 | UNRUN |
| Tools与返回 | 翻译、地址卡、安全短语名称完整；进入/返回路径可操作 | UNRUN |
| 切换中英 | 切换后文字与朗读语言合理，已有草稿不丢失 | UNRUN |

“能在截图看见”不等于旁白通过；“能朗读整句”也不能代替视觉裁切检查。
操作参考：[Apple旁白开启与练习](https://support.apple.com/guide/iphone/turn-on-and-practice-voiceover-iph3e2e415f/ios)。

## 5. 最大字号、深色与减弱动态效果

先记住个人原设置，以便测试后恢复。

1. “设置 → 辅助功能 → 显示与文字大小 → 更大字体”，开启更大的辅助功能字体范围并把滑块移到最大。
2. 回到App，中英各检查 Ask/Trip/Tools。必要时滚动：每段应能完整读到，按钮文字能辨认，焦点能到达。
   滚动视口边缘暂时只露半行，不能直接算整段丢失；要确认能否继续滚到完整内容。
3. 特别记录中文预览说明末尾、Tools折行名称和Trip编号的截图；发现文字始终无法看全时记FAIL。
4. “设置 → 显示与亮度”改为深色，重复阅读与旁白检查；文字不能与背景混在一起。
5. “设置 → 辅助功能 → 动态效果 → 减弱动态效果”开启，按住/点选页面入口并返回；应保留状态反馈，
   不依赖明显缩放位移才能理解操作。不能只看开关已开启就记通过。
6. 完成后恢复原字号、外观和动态效果设置；按需要关闭旁白。

参考：[Apple字号调整](https://support.apple.com/en-au/102453)、[Apple减弱动态效果](https://support.apple.com/en-us/111781)。
