## Stable callable interface

- `NativeSubscriptionView(scope:chinese:port:legacyEntitlements:dataControls:)` is a generic SwiftUI destination; both destination builders are required, preserving existing controls rather than copying their implementation.
- `NativeSubscriptionSessionReadPort(scope:get:)` receives a live MainActor scope getter and a GET closure. Public catalog reads need no account; private entitlement reads recheck live valid scope before and after the await. `NativeSubscriptionRequest` includes optional `scope`, `.catalog(.zh/.en)` or `.entitlement`, and a client-only UUID `nonce`. Nonce/generation are local concurrency fences, not server authority or proof of purchase. No echo field is assumed in either producer wire.
- Only `.catalog` may have nil scope; the Store always sends catalog requests with nil scope. `.entitlement` must have a non-nil valid scope and the production port rejects nil before invoking GET. Scope has `endpoint`, lowercased authenticated `ownerID`, `mobileEpoch`, `generation`, matching existing `NativeDataScope`. Scope/Session must be read live, not captured at initial view construction. A session-generation change immediately hides private values before view lifecycle tasks run.
- Every resource returns a closed `{ "data": producerProjection }` envelope. Catalog resource is `subscriptionDevelopmentPresentation(locale)` from AGENT018 commit `1fd9669d43a2febae96c29949ebbadd211f42a53`, not the entire capacity catalog. Entitlement resource is the unchanged AGENT009 `Snapshot` (`subscription-entitlement/1`, lease-final contract in `ebd4fe0a70d67d3bc7fafb768f49b75c656bc34c`, SHA256 `4e2b4b65d8f481b9c91e29b1eff848e71ae16b318de61f87a9cb719db721841e`). No response field enables purchases/capacity.
- Strict parser rejects unknown/missing fields, altered versions, malformed/null/wrong types, positive or zero remainingCapacity, unknown environments/states, localTest claims, cross-owner values and invalid periods. Sandbox active/expired/revoked are explicitly labelled as Sandbox test periods; unavailable/reconciliation never mean none/zero. Current backend refuses local Xcode source; this reader does too. The final wire requires checkedAt and lifetimeMs (integer 0...300000). Only active has a positive lifetime; all other states have 0, and unavailable/reconciliation have null checkedAt. Native reads no device calendar for eligibility. It subtracts the entire catalog+entitlement round trip using ContinuousClock, hides active at the half-open monotonic deadline and never manufactures an expired receipt. Same-check readback and failed refresh do not extend the original deadline; a new trusted checkedAt is required. Nonpositive historical states show their last server check time, never grant authority. B alone computes lifetime against serverNow, original verification+5min and period expiresAt.
- Reload clears old private data. A closed-codec-validated public catalog is published immediately after its own response, may load without an account, and survives private failures/account changes if locale/schema/request qualification still matches. Locale changes clear a mismatched public catalog; foreground/current nonce/locale gate late public responses. Background/inactive, disappear, actor/endpoint/epoch/generation changes and active lease expiry invalidate it. Errors do not restore stale data. No cache, credential/receipt store, StoreKit import, network client or write capability exists. Unconfigured port is genuinely unavailable, never fake success.
